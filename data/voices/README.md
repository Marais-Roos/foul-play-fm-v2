Once added, they will be uploaded to the Fish Audio voice cloning API using `scripts/clone-voices.ts`.

## Supported Formats:
- Sample rate: 44.1 kHz or 48 kHz recommended
- Length: 15–60 seconds of clean, isolated dialogue with no background music
- File extension: `.wav`, `.mp3`, or `.m4a`
